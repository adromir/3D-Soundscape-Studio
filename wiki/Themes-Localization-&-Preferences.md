# 🎨 Themes, Localization & Preferences

3D Soundscape Studio is designed with visual excellence, ergonomics, and accessibility in mind, providing 8 handcrafted themes, high-contrast light mode, and full 5-language internationalization.

---

## 🎭 Thematic Styles (8 Visual Styles)

Switch themes seamlessly via **View > Thematic Style** or in the **Preferences** dialog (`Ctrl + ,`):

1. **🎋 Tactile Organic Zen**: Crafted with authentic stone textures, natural bamboo panels, amber gold accents, and subtle earthy aesthetics.
2. **🌌 Aetheric Dark Studio**: A sleek, professional DAW theme featuring deep charcoal slate panels, high-contrast gold accents, and minimal eye strain for long mixing sessions.
3. **⚡ Cyberpunk Neon**: A high-energy futuristic aesthetic with luminous cyan framing, hot magenta glows, and high-tech polar grid coordinates.
4. **☀️ High-Contrast Studio Light**: A bright, ultra-crisp daylight mode with pure white text on solid blue active buttons, pure dark slate unpressed controls, and maximum outdoor readability.
5. **🏰 Warm Fantasy**: Parchment tones, warm wood accents, and golden highlights ideal for RPG ambience design.
6. **🛸 Holo Sci-Fi**: Deep navy blue backing with electric blue neon glowing rings and data overlays.
7. **📜 Antique Sepia**: Vintage amber sepia textures with classic analog aesthetic.
8. **🌊 Abyss Ocean**: Deep oceanic blues and glowing aquamarine accents.

---

## 🌍 5-Language Localization

3D Soundscape Studio includes native multi-language support:
- 🇬🇧 **English** (`en`)
- 🇩🇪 **German / Deutsch** (`de`)
- 🇫🇷 **French / Français** (`fr`)
- 🇪🇸 **Spanish / Español** (`es`)
- 🇮🇹 **Italian / Italiano** (`it`)

Switch languages instantly in **View > Language** or in the Preferences dialog. All UI strings, MenuBar items, dialog prompts, tooltips, dock headers, inspector labels, and status messages update immediately without requiring an application restart.

## ⚙️ Preferences Dialog (`Ctrl + ,`)

![Preferences Dialog](https://raw.githubusercontent.com/adromir/3D-Soundscape-Studio/main/docs/images/07_preferences_dialog.png)

Configure application-wide settings:
- **Audio Output Device & Buffer Size**: Adjust latency vs. stability.
- **Default Soundspace Radius**: Set default radar scale (e.g. $10\text{ m}$, $20\text{ m}$, $30\text{ m}$).
- **Default Theme & Language**: Persist your preferred visual style and language across sessions in `data/settings.json`.
- **Automatic Updates**: Toggle `Check for updates automatically on startup` to keep your studio up-to-date with latest GitHub releases.
- **Auto-Save & Workspace Sync**: Real-time preference synchronization across all UI components.

## 🚀 GitHub Releases Auto-Updater

Check for new versions directly within the application:
- Accessible anytime via **Help > Check for Updates...** (`Hilfe > Nach Updates suchen...`).
- Displays formatted markdown release notes, version comparison (`v2.0.0` ➔ `v2.1.0`), and download progress.
- Seamlessly downloads and executes the update script on Windows / Linux to replace application binaries and restart automatically.
