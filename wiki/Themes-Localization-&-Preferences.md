# 🎨 Themes, Localization & Preferences

3D Soundscape Studio is designed with visual excellence, ergonomics, and accessibility in mind, providing handcrafted organic tactile themes and multi-language internationalization.

---

## 🎭 Thematic Styles

Switch themes seamlessly via **View > Thematic Style** or in the **Preferences** dialog (`Ctrl + ,`):

### 1. 🎋 Tactile Organic Zen (Default)
Crafted with authentic stone textures, natural bamboo panels, amber gold accents, and subtle earthy aesthetics.

### 4. ☀️ High-Contrast Light

## 🌍 Multi-Language Localization

3D Soundscape Studio includes native multi-language support:
- **English** (`en`)
- **German / Deutsch** (`de`)

Switch languages instantly in **View > Language** or in the Preferences dialog. All UI strings, menu labels, dialog prompts, tooltips, and status messages update immediately without requiring an application restart.

---

## ⚙️ Preferences Dialog (`Ctrl + ,`)

![Preferences Dialog](../docs/images/07_preferences_dialog.png)

Configure application-wide settings:
- **Audio Output Device & Buffer Size**: Adjust latency vs. stability.
- **Default Soundspace Radius**: Set default radar scale (e.g. $10\text{ m}$, $20\text{ m}$, $30\text{ m}$).
- **Default Theme & Language**: Persist your preferred visual style and language across sessions.
- **Auto-Save & Workspace Sync**: Real-time preference synchronization across all UI components.
